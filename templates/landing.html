安裝方式

只需要 5 分鐘，完全免下載安裝程式

1

下載 Chrome 擴充套件

到下方連結下載擴充套件 ZIP 檔，解壓縮到任意資料夾。

2

開啟 Chrome 擴充套件頁面

在 Chrome 網址列輸入 chrome://extensions/，開啟右上角「開發人員模式」。

3

載入擴充套件

點「載入未封裝項目」，選擇剛才解壓縮的資料夾，套件就會出現在 Chrome 工具列。

4

用 Google 帳號登入

點工具列的 5888 小編助手 圖示 → 前往登入，用 Google 帳號登入，新用戶自動取得 100 點。

常見問題

需要安裝任何程式嗎？ ▼

不需要。只需要安裝一個 Chrome 擴充套件，其他都在網頁上操作。Windows / Mac 都支援。

會不會被 Threads 封號？ ▼

工具模擬人工操作，有每日 100 次的上限保護。建議留言內容自然，避免重複發相同文字。任何自動化工具都有一定風險，請自行評估。

點數用完了怎麼辦？ ▼

可以聯絡我們加購點數，或等下個月方案自動補點。AI 改寫生成功能不扣點，可以無限使用。

需要自己的 Gemini API Key 嗎？ ▼

是的，AI 生成功能需要你自己的 Google Gemini API Key（免費申請，有每日免費額度）。這樣你的 AI 配額完全由你掌控。

如何取得 Threads API Token？ ▼

需要到 Meta for Developers 申請 Threads API 存取權限。申請流程約 1-2 天審核，我們有提供詳細教學。
